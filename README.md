# feature_sidescrolling

## 概要
このリポジトリは、サイドスクロールゲームの機能を実装するためのものです。プレイヤーは左右に移動し、ジャンプすることができます。

## コンテナ起動方法
```bash
docker compose -f compose.prod.yml up -d --build
```

## 開発コンテナ起動方法
```bash
docker compose up -d --build
```
VSCodeでコンテナに接続


## 操作方法
| 操作 | 対応キー |
| ---- | ---- |
| 右へ移動 | D |
| 左へ移動 | A |
| ジャンプ | スペース |
